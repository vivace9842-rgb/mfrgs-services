# MFRGS Engineering Control System (MECS)

## Objetivo

Esta pasta define a organização oficial dos agentes da MFRGS.

Nenhum agente pode atuar sem:

- Missão definida
- Limites definidos
- Supervisor definido
- Política STOP definida
- Homologação

O Documento Mestre continua sendo a autoridade máxima do projeto.

Os agentes executam.

Os supervisores fiscalizam.

O Product Owner aprova.

Toda alteração arquitetural deve ser documentada antes da implementação.
